# Changelog

## First release

- Visual editor panel for `carcols.meta`, `carvariations.meta` and `vehicles.meta`, next to the text and synced both ways.
- Siren settings: 32-step sequencer grid with pattern tools, every siren field, head/tail sequences, siren labels and an animated preview you can lay out on the car, with rotation speed tools.
- Mod kits: parts grouped under category headers, sub-sections, folding, comment out / enable, change a whole category, categories used and free, stats with part and linked-model limits, slot names, linked models with linkMods, and handling for parts pasted in from another kit.
- Shop names: linked `vehicle_names.lua`, edited from the panel and filed into per-vehicle sections.
- Bulk edit across every kit in the file: counts, missing kits, comment out, delete, add to all kits and reorder, each as a single undo step.
- Rename tool for the kit you're editing, with preview and regex.
- Variations tab: spawn colour sets with game colour names and a palette, kits, siren setting, lights and plates.
- Vehicles tab: every vehicles.meta field, grouped and typed, plus txdRelationships and checks.
- Checks: shop labels, formatting mistakes (with a warning on save), siren IDs and counts, kit limits, missing linkMods, with an option to only show problems in the current kit.
- Change markers since the last save, in the panel and the text.
- ↗ Show in file on parts, categories, sirens, slots, linkMods, colour sets, bulk rows and vehicle fields.
- Text editor helpers: colour swatches and picker, sequencer hovers and inline patterns, colour names, completions and a linkMods quick fix.
